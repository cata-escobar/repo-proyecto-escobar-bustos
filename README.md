# Blur vs. Oasis: la batalla que no terminó en 1995

Este repositorio contiene el desarrollo del proyecto de investigación sobre la rivalidad 30 años después entre Blur y Oasis, dos de las bandas más representativas del Britpop de los años 90. A partir de la construcción y análisis de una base de datos propia, el proyecto busca comparar sus trayectorias y explorar cómo se relacionan su éxito histórico y comercial con su vigencia e impacto cultural.

Para ello, se recopilarán y sistematizarán datos provenientes de fuentes oficiales, plataformas digitales y sitios especializados, considerando variables como ventas, certificaciones, rankings, premios, giras, reproducciones, seguidores y presencia en la cultura popular.

El repositorio reúne los avances, bases de datos, análisis y entregas correspondientes al desarrollo del proyecto.
